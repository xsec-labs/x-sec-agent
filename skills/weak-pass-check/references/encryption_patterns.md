# Web 登录加密与编码特征识别指南

本参考文档帮助识别登录表单中用于混淆密码或其他敏感数据的常见加密和编码方式。

## 常见特征标志

### Base64 编码
- **特征**：字符串以 `=` 或 `==` 结尾，字符集为 `A-Z、a-z、0-9、+、/`。
- **识别方法**：在浏览器控制台使用 `atob()` 解码，或检查字符串长度是否为 4 的倍数。

### Hex（十六进制）编码
- **特征**：字符串仅包含 `0-9、a-f`。
- **说明**：常用于表示原始加密字节或哈希值。

### AES（高级加密标准）
- **特征**：
    - JavaScript 库：`crypto-js`、`sjcl`。
    - 存在 `iv`（初始向量）、`mode`（CBC/ECB/GCM）、`padding`（Pkcs7）等参数。
    - 密钥长度通常为 16、24 或 32 字节。
- **JS 关键词**：`CryptoJS.AES`、`aes-cbc`、`encrypt`。

### RSA（非对称加密）
- **特征**：
    - 存在公钥（以 `-----BEGIN PUBLIC KEY-----` 开头）。
    - 使用 `jsencrypt`、`forge` 等库。
    - 加密后的载荷通常很长（2048 位 RSA 产生 256 或 512 个字符）。
- **JS 关键词**：`JSEncrypt`、`setPublicKey`、`encrypt`。

### DES / 3DES
- **特征**：
    - 多见于老旧站点。
    - 使用 `CryptoJS.DES`、`CryptoJS.TripleDES`。
- **识别**：以 8 字节为分组单位。

### SM2 / SM4（国密算法）
- **特征**：
    - 使用 `sm-crypto` 库。
    - SM2 为非对称加密（公私钥），SM4 为对称加密。
- **JS 关键词**：`sm2`、`sm4`、`doEncrypt`。

### 哈希算法（MD5 / SHA1 / SHA256）
- **MD5**：32 个十六进制字符。
- **SHA1**：40 个十六进制字符。
- **SHA256**：64 个十六进制字符。

## 分析步骤
1. **Network 面板**：找到登录请求，观察哪些参数值不可读。
2. **搜索源码**：在 JavaScript bundle 中搜索对应参数名。
3. **打断点**：在 DevTools 中使用"XHR/Fetch 断点"或"事件监听断点（点击）"，在数据发送前找到处理逻辑。
