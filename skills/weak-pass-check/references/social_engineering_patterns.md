## 心理学核心原则

人类在创建密码时可预测地受到以下认知偏差影响：

| 偏差 | 描述 | 社工利用方式 |
|------|------|-------------|
| **熟悉性启发** | 倾向于使用与当前环境相关的词汇 | 域名、公司名、产品名作为词根 |
| **认知懒惰** | 选择最小认知负担的满足策略 | 简单数字后缀 (123, 123456) |
| **安于现状** | 沿用已记住的模式，只做最小改动 | 同一词根+不同年份 |
| **情感锚定** | 重要日期/数字有极强记忆优势 | 生日、纪念日、幸运数字 |
| **小聪明安全感** | 字符替换让人感觉"安全" | a→@, e→3 |
| **动作依赖** | 想到的密码是手指能快速打出的 | 键盘行走 |
| **环境提示** | 季节/节日触发密码更新 | Spring2025, Summer2024 |
| **社会认同** | 模仿常见密码模式 | admin123, password123 |

## 数字后缀模式

**心理原理**: 认知懒惰 + 复杂性最小努力

用户被要求"密码必须包含数字"时，最省力的做法是在单词末尾添加数字：

```
{公司名}123       ← 最常见
{公司名}123456    ← "我多用几个数字，更安全"
{公司名}888       ← 中国用户：幸运数字
```

常见数字后缀频率（基于泄露数据库统计）:
- `123` / `1234` / `12345` / `123456` — 80%+
- `111` / `222` / `...` / `999` — 重复数字有记忆优势
- `666666` / `888888` — 中国用户高频

## 情感/幸运数字

**心理原理**: 情感锚定

| 数字 | 文化含义 | 生成场景 |
|------|---------|----------|
| `520` | 我爱你 | admin520, root520, {domain}520 |
| `521` | 我愿意 | 类似 520 |
| `1314` | 一生一世 | admin1314, root1314 |
| `168` | 一路发 | 商务场景 |
| `666` | 溜溜溜（厉害） | admin666 |
| `888` | 发发发 | admin888, {domain}888 |

## 特殊符号模式

**心理原理**: 边缘满足策略

当系统要求"必须包含特殊符号"时，用户倾向于：
1. 只加一个符号（通常是第一个想到的 `!` 或 `@`）
2. 加在末尾
3. 和数字一起加

```
{word}!
{word}@123      ← "@123" 是最省力的符号+数字组合
{word}#123
{Word}123!@#    ← 键盘上紧挨着的三个键
```

## 年份/日期锚定

**心理原理**: 事件锚定 + 密码过期应对

当被要求定期更换密码，或创建与工作相关的密码时：
- 创建年份 `{word}2018`
- 当年年份 `{word}2025` (最常见的"新密码")
- 当年+符号 `{word}@2025`
- 生日 `YYYYMMDD`
- 发薪日 `20250128` (28号为常见中国发薪日)

## 键盘行走

**心理原理**: 动作依赖（肌肉记忆）

手指在键盘上"行走"是最容易打出的密码模式，不需要记忆具体字母：

```
qwerty        ← QWERTY键盘第一行
1qaz2wsx      ← 左手+右手交替向下
asdfgh        ← home row 横向移动
zaqxsw        ← 左下角区域
```

## Leet Speak 替换

**心理原理**: 小聪明式安全感觉

用户知道"密码不应该用常见单词"，于是用符号替换相似字母：
```
a → @    password  → p@ssw0rd
e → 3    security → s3curity
i → 1    admin    → adm1n
o → 0    root     → r00t
s → $    welcome  → welc0me
```

## 领域关联词

**心理原理**: 熟悉性启发 + 场景对应

员工倾向于使用与工作直接相关的词汇作为密码：
- 公司名 / 品牌名
- 产品名 / 项目代号
- 部门名
- 使用的软件名（oracle, nginx, redis）
- 域名本身

---

## 密码重用与变体

**心理原理**: 安于现状 + 最小改动

同一人跨系统的密码往往是同一基础词的微小变体：
```
{word}2023  → {word}2024  （仅换年份）
{word}123   → {word}@123  （按要求加符号）
{word}!     → {Word}!     （按要求加大写）
```

## 应用指南

生成社工字典时，遵循以下优先级：

1. **先精准**: 用 `social_combined.txt`（少量高质量组合）进行快速精准爆破，命中率最高
2. **再喷洒**: 用 `social_passwords.txt` 配合用户名枚举结果进行密码喷洒
3. **最后全面**: 补以 `TOP603密码.txt` 等通用字典

**典型命中率层叠**:
- 社工字典: 10-25% 命中率（针对目标定制）
- TOP603 + TOP241: 5-10%（通用弱口令）
- 全量字典: 1-3%（覆盖长尾）
