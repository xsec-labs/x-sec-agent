# 运行边界与证据口径

适用于入口、主代理、子代理、模板和配置；技能文本不改变宿主指令。本文与批量系统提示词、
MCP 服务端的实际行为一致；两处不一致时以系统提示词和当前工具列表为准。

- **范围只做归因**：`scope_policy`、`in_scope` 只用来标注资产归属和审计，不是网络访问边界，
  也不是放行证明；`in_scope=false` 不是停止理由。页面、脚本、DNS、重定向和文档里自然发现的
  HTTP/HTTPS 目标可以继续测试，记录来源即可。访问仍受 capability、身份、session/run、
  browser session/page group 所有权、宿主审批和下面的低影响约束。
- `page_group_id` 仅作路由归因，不提供浏览器隔离。影响共享状态的操作（context 级清理、
  Cookie 或存储批量变更）要先考虑对其它 Agent 的并发影响。
- **低影响**：禁止破坏性操作、DoS、无界字典爆破、高并发扫描、横向移动和批量数据获取；
  不修改、删除或覆盖真实业务数据，不改真实用户密码。遇锁定、验证码升级、风控、速率限制或
  服务异常立即停止相关动作，记录阻断，不绕过、不扩大预算。遵守请求量、并发和时间上限。
- **证据保留原始值**：xSec 不做自动脱敏。流量和证据按观察到的原始内容保存和返回
  （Authorization、Cookie、token、密码字段等），可在本次任务内用于关联、重放和验证。
  截断只因体积限制，必须用 `truncated` 等字段明确标记，不得用 `***`、`REDACTED` 等掩码替换。
- 写入共享发现、正式 finding、证据和报告时，只选与复现和结论直接相关的最小原始片段；
  不要把无关的完整凭据复制到最终回复。保留原始证据与展示副本的对应关系。
- `candidate` 只有在已有充分证据时才能标为 `validated`。记录未覆盖或阻断项。
- 技能源目录运行时只读；所有运行产物写入指定运行目录。完成分配范围后结束，
  新线索回填为共享发现，由主 Agent 决策，不自动形成无界任务链。

这些是 Agent 行为约束；运行时强制隔离、访问控制和秘密存储能力由宿主独立提供。
